# ah shader

Minecraft Java Edition용 가벼운 쉐이더팩입니다. 내장 그래픽 노트북에서도 높은 fps가 나오는 것을 목표로 만들었습니다.

- 대상: Minecraft 1.20.1, Fabric, Iris 1.7.6, Sodium 0.5.13
- 버전: 2.2.1

## 내려받기

[ah shader.zip](https://github.com/cerbagge/ah-shader/raw/main/dist/ah%20shader.zip)

## 설치 방법

1. Minecraft 1.20.1에 Fabric, Sodium, Iris를 설치합니다.
2. `ah shader.zip`을 압축을 풀지 않고 `.minecraft/shaderpacks` 폴더에 넣습니다.
3. 게임에서 `설정 → 비디오 설정 → 셰이더 팩`을 열고 `ah shader.zip`을 고른 뒤 적용합니다.
4. 같은 화면의 `셰이더 팩 설정`에서 세부 설정을 바꿀 수 있습니다. 설정 이름과 설명은 한국어와 영어로 제공합니다.

## 사양

이 쉐이더팩은 컴퓨터 한 대에서만 시험했습니다. 권장 사양은 그 컴퓨터에서 실제로 측정한 결과이고, 최소 사양은 쉐이더가 사용하는 기능에서 도출한 기술적 요구 사항이며 해당 사양의 컴퓨터에서 직접 시험하지는 못했습니다.

### 최소 사양 (동작 기준)

| 항목 | 내용 |
|---|---|
| 게임 | Minecraft Java Edition 1.20.1, Fabric, Sodium 0.5.x, Iris 1.7.x |
| 그래픽 | OpenGL 3.3을 지원하고 Sodium과 Iris가 동작하는 그래픽카드. 내장 그래픽도 가능합니다. |
| 그래픽 메모리 | 쉐이더가 추가로 쓰는 양은 1920x1080 기준 약 100MB 이내입니다(버퍼 크기로 계산한 값). |
| 운영체제 | Windows에서 시험했습니다. macOS와 Linux는 시험하지 못했습니다. |

최소 사양에서는 광원별 조명 색, 색유리를 통과한 조명의 색, 엔드 차원문 틀 발광이 자동으로 꺼질 수 있습니다. 이 세 기능은 OpenGL 4.3을 지원하는 그래픽카드가 필요합니다.

DLSS나 FSR 같은 업스케일링 전용 기능을 지원하는 그래픽카드는 필요하지 않습니다.

### 권장 사양 (렌더 거리 12청크에서 90~150fps)

| 항목 | 내용 |
|---|---|
| CPU | Intel Core Ultra 7 155H급 이상 |
| 그래픽 | Intel Arc 내장 그래픽(Core Ultra 시리즈)급 이상, OpenGL 4.3 이상 지원 |
| 시스템 메모리 | 시험한 컴퓨터는 32GB입니다. 쉐이더 자체는 메모리를 거의 쓰지 않으므로 게임이 요구하는 만큼이면 됩니다. |
| 화면 | 시험한 창 크기는 2880x1676이며, 렌더 배율 50%로 측정했습니다. |

위 fps는 기본 설정(렌더 배율 50%, 그림자 켬, 그림자 거리 48블록, 엔티티 그림자 끔)에서 측정했습니다. 하늘을 볼 때에는 200fps 이상, 몹이 많은 해변에서는 110~120fps, 숲에서는 90fps 안팎이 나왔습니다.

### 사양이 낮을 때

fps가 부족하면 다음 순서로 조정해 보시기 바랍니다.

1. 게임의 렌더 거리를 낮춥니다. 가장 효과가 큽니다.
2. `그림자 → 그림자 거리`를 줄이거나 `그림자`를 끕니다.
3. `조명 → 광원별 조명 색`을 끕니다.
4. `업스케일링 → 렌더 배율`이 50%인지 확인합니다.

## 기능

- **저해상도 렌더링과 시간적 업스케일링**: 화면을 낮은 해상도로 그린 뒤, 이전 프레임들의 정보를 모아 화면 해상도까지 복원합니다. DLSS, FSR과 같은 원리이지만 쉐이더 코드로 직접 구현했기 때문에 그래픽카드 종류와 관계없이 동작합니다. NVIDIA DLSS 기술 자체를 사용하는 것은 아닙니다.
- **그림자**: 부드러운 가장자리, 색유리를 통과한 햇빛의 색 표현.
- **광원별 조명 색**: 횃불은 주황색, 영혼 불은 푸른색, 레드스톤은 붉은색으로 주변을 밝힙니다. 조명이 색유리를 통과하면 유리 색으로 물들고, 벽은 조명 색을 막습니다.
- **엔드 차원문 틀 발광**: 원래 빛을 내지 않는 엔드 차원문 틀이 청록색 빛을 냅니다.
- **물**: 물결, 하늘 반사, 깊이에 따라 달라지는 투명도.
- **야간 투시 모드**: 물약 없이도 어두운 곳을 밝게 볼 수 있습니다.
- **한국어 설정 화면**: 업스케일링, 그림자, 조명, 하늘·안개, 물, 색감의 6개 분류에 39개 설정이 있습니다.

## fps에 대하여

fps에 가장 큰 영향을 주는 것은 쉐이더 설정이 아니라 게임의 **렌더 거리**입니다. 쉐이더를 켠 상태에서 fps가 낮으면 렌더 거리를 먼저 낮춰 보시기 바랍니다. 개발에 사용한 노트북(Intel Arc 내장 그래픽, 2880x1676 창)에서는 렌더 거리 12청크에서 장면에 따라 90~150fps가 나왔습니다.

쉐이더 설정 중에서는 `렌더 배율`, `그림자`, `그림자 거리`, `엔티티 그림자`가 fps에 영향을 줍니다.

## 알려진 제한

- 광원별 조명 색, 색유리를 통과한 조명의 색, 엔드 차원문 틀 발광은 OpenGL 4.3 기능을 사용합니다. macOS처럼 이 기능을 지원하지 않는 환경에서는 자동으로 꺼지고 나머지 기능만 동작합니다. macOS 실기에서는 시험하지 못했습니다.
- 위 세 기능은 플레이어 주변 32블록 안에서만 동작합니다.
- 시험한 환경은 Iris 1.7.6, Sodium 0.5.13, Minecraft 1.20.1 하나입니다. OptiFine에서는 시험하지 않았습니다.
- 빠르게 움직일 때 업스케일링으로 인한 잔상이 약간 생길 수 있습니다. `업스케일링 → 화면 반응 속도`로 조절합니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `shaders/` | 쉐이더팩 본체 |
| `dist/ah shader.zip` | 배포용 압축 파일 |
| `tools/gen_config.py` | `shaders.properties`, `block.properties`, `lang/*.lang`을 생성하는 스크립트 |
| `tools/ShaderCheck.java` | 실제 그래픽 드라이버에서 모든 쉐이더를 컴파일·링크해 보는 검사 도구 (LWJGL 3 필요) |

설정을 추가하려면 `shaders/lib/settings.glsl`에 정의를 넣고 `tools/gen_config.py`의 표에 이름과 설명을 추가한 뒤 스크립트를 실행합니다. `shaders.properties`, `block.properties`, `lang/*.lang`을 직접 고치면 다음 실행 때 덮어써집니다.
